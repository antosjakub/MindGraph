# MindGraph

I am a math / physics student.
I like to organize / sketch my notes on a large paper into a mind-map like style.
This project seeks to reproduce this in a digital form.


## Shortcuts

| Key                 | Action                       |
| ------------------- | ---------------------------- |
| H / J / K / L       | Pan the board view           |
| S                   | Pin/release node at crosshair while panning |
| A                   | Add node or field at crosshair |
| C                   | Toggle connection from node under crosshair |
| G                   | Group selected               |
| B                   | Toggle boards panel          |
| F                   | Fit view                     |
| Enter               | Edit item under crosshair    |
| D                   | Delete item under crosshair  |
| Delete              | Delete selected              |
| Esc                 | Cancel / close               |
| + / -               | Zoom in/out                  |
| Ctrl+A              | Select all                   |
| Shift+click         | Multi-select                 |
| Shift+drag          | Rectangle select             |
| Double-click canvas | Create node at cursor        |
